# reality-connect-public-memory

**Purpose**: Public, shareable memory for the X version of Grok (and other agents) to stay current on Reality Connect development. Enables timely, accurate posts about progress, features, and updates.

This repo holds non-sensitive context that should be known publicly or by AI posting on X. Private notes live in the companion private repo.

## Structure
- `/memories/` — Topic-specific Markdown files (e.g. development updates, feature notes).
- `/posts/` — Drafts or templates for X posts.
- `README.md` — This file.

## How to use (for Grok / agents)
1. Check this repo for latest development notes before posting about Reality Connect.
2. Prefer event-driven or low-frequency updates; avoid over-posting.
3. Key goal: Increase visibility of Reality Connect through accurate, timely posts.
